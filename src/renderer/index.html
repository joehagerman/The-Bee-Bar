      Bee Authentication

      Authenticate using your Bee Developer Bearer Token or point to your running local proxy.

      How to sign into your Bee Developer account:
      • Method 1 (Instant Bearer Token): In the Bee mobile app where you signed in, go to Settings → tap the version number 5 times to reveal Developer Mode → tap API Access / Token to copy your Bearer Token, and paste it below.
      • Method 2 (QR Code Login via CLI): Run bee login --qr in your terminal and scan the QR code with your Bee app. Then run bee proxy to connect locally on port 8787 without needing to copy tokens!
